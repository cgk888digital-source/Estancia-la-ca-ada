# Estancia La Cañada - Mobile MVP

Este proyecto contiene la interfaz de inicio (Home Screen) de lujo para la aplicación móvil de Estancia La Cañada.

## Estado Actual
- **Framework**: React + Vite + TypeScript.
- **Estilos**: Tailwind CSS v4 (configurado con `@tailwindcss/postcss`).
- **Componentes**: 
  - `EstanciaHome.tsx`: Pantalla principal con diseño "Rustic-Premium", alineación perfecta, animaciones con `framer-motion` y glassmorphism.

## Cómo retomar el trabajo
Para volver a levantar el entorno después del reinicio:
1. Abre una terminal en esta carpeta.
2. Ejecuta: `npm install` (por si acaso).
3. Ejecuta: `npm run dev` para iniciar el servidor de desarrollo.
4. Abre: `http://localhost:5173/` en tu navegador.
